Transformer 架构中的数学美学与注意力机制推导

在自然语言处理和计算机视觉中，Transformer 已经成为了几乎所有主流大模型（LLM）的基石。其核心算子 —— 自注意力机制 (Self-Attention) 巧妙地通过向量内积捕捉了序列内任意两点之间的长距离关联。

本篇文章我们将以极其严谨的数学视角，系统推导其缩放因子 dk\sqrt{d_k}dk​​ 的由来，并探讨为什么在高维空间下，内积的方差膨胀会成为模型训练的“毒药”。

自注意力机制的定义

首先，我们给出注意力机制的代数描述：

定义 1：缩放点积注意力 (Scaled Dot-Product Attention)
给定输入 Query 矩阵 $Q \in \mathbb{R}^{n \times d_k}$，Key 矩阵 $K \in \mathbb{R}^{m \times d_k}$，以及 Value 矩阵 $V \in \mathbb{R}^{m \times d_v}$。

其缩放点积注意力输出定义为： Attention(Q,K,V)=softmax(QKTdk)V\text{Attention}(Q, K, V) = \text{softmax}\left( \frac{QK^T}{\sqrt{d_k}} \right) VAttention(Q,K,V)=softmax(dk​​QKT​)V

其中：

  • nnn 和 mmm 分别代表 Query 序列与 Key/Value 序列的长度。
  • dkd_kdk​ 代表 Query 和 Key 的维度（通道数）。
  • dk\sqrt{d_k}dk​​ 即为缩放因子 (Scale Factor)。

为什么缩放因子是 dk\sqrt{d_k}dk​​？

在 Vaswani 等人的原始论文《Attention Is All You Need》中提到，当 dkd_kdk​ 较小时，点积注意力的表现与相加注意力（Additive Attention）相似；然而当 dkd_kdk​ 较大时，如果不进行缩放，点积注意力的表现会急剧变差。

我们将这一现象提炼为以下数学定理并予以严格证明：

定理 1：高维向量内积的方差膨胀性质
设 Query 向量 $q \in \mathbb{R}^{d_k}$ 与 Key 向量 $k \in \mathbb{R}^{d_k}$ 为相互独立的随机向量。假设它们的每个分量 $q_i$ 和 $k_i$ 均是独立同分布 (i.i.d.) 的随机变量，且满足均值为 0、方差为 1 的标准分布： $$\mathbb{E}[q_i] = \mathbb{E}[k_i] = 0, \quad \text{Var}(q_i) = \text{Var}(k_i) = 1$$

则在未缩放前，它们的点积 q⋅k=∑i=1dkqikiq \cdot k = \sum_{i=1}^{d_k} q_i k_iq⋅k=∑i=1dk​​qi​ki​ 满足： E[q⋅k]=0,Var(q⋅k)=dk\mathbb{E}[q \cdot k] = 0, \quad \text{Var}(q \cdot k) = d_kE[q⋅k]=0,Var(q⋅k)=dk​

证明过程：

根据期望的线性性质，由于 qiq_iqi​ 与 kik_iki​ 相互独立，其乘积的期望为： E[qiki]=E[qi]E[ki]=0×0=0\mathbb{E}[q_i k_i] = \mathbb{E}[q_i] \mathbb{E}[k_i] = 0 \times 0 = 0E[qi​ki​]=E[qi​]E[ki​]=0×0=0

因此，整体内积的期望为： E[q⋅k]=E[∑i=1dkqiki]=∑i=1dkE[qiki]=0\mathbb{E}[q \cdot k] = \mathbb{E}\left[ \sum_{i=1}^{d_k} q_i k_i \right] = \sum_{i=1}^{d_k} \mathbb{E}[q_i k_i] = 0E[q⋅k]=E[∑i=1dk​​qi​ki​]=∑i=1dk​​E[qi​ki​]=0

接下来计算单项乘积 qikiq_i k_iqi​ki​ 的方差。由于方差的定义为 Var(X)=E[X2]−(E[X])2\text{Var}(X) = \mathbb{E}[X^2] - (\mathbb{E}[X])^2Var(X)=E[X2]−(E[X])2，我们有： Var(qiki)=E[(qiki)2]−(E[qiki])2\text{Var}(q_i k_i) = \mathbb{E}[(q_i k_i)^2] - (\mathbb{E}[q_i k_i])^2Var(qi​ki​)=E[(qi​ki​)2]−(E[qi​ki​])2

由于 qiq_iqi​ 和 kik_iki​ 独立，上式可写作： Var(qiki)=E[qi2]E[ki2]−0\text{Var}(q_i k_i) = \mathbb{E}[q_i^2] \mathbb{E}[k_i^2] - 0Var(qi​ki​)=E[qi2​]E[ki2​]−0

由于已知 Var(qi)=E[qi2]−(E[qi])2=1  ⟹  E[qi2]=1\text{Var}(q_i) = \mathbb{E}[q_i^2] - (\mathbb{E}[q_i])^2 = 1 \implies \mathbb{E}[q_i^2] = 1Var(qi​)=E[qi2​]−(E[qi​])2=1⟹E[qi2​]=1，同理 E[ki2]=1\mathbb{E}[k_i^2] = 1E[ki2​]=1。 带入可得： Var(qiki)=1×1=1\text{Var}(q_i k_i) = 1 \times 1 = 1Var(qi​ki​)=1×1=1

由于各维度分量独立同分布，内积的方差即为各维度分量方差之和： Var(q⋅k)=Var(∑i=1dkqiki]=∑i=1dkVar(qiki)=∑i=1dk1=dk\text{Var}(q \cdot k) = \text{Var}\left( \sum_{i=1}^{d_k} q_i k_i \right] = \sum_{i=1}^{d_k} \text{Var}(q_i k_i) = \sum_{i=1}^{d_k} 1 = d_kVar(q⋅k)=Var(∑i=1dk​​qi​ki​]=∑i=1dk​​Var(qi​ki​)=∑i=1dk​​1=dk​

证明毕。

核心推论：
由上述证明可知，内积的点积值的方差正比于通道维度 $d_k$。当维度 $d_k$ 很大时（例如在 GPT-3 中，维度 $d_{model} = 12288$），内积的绝对值很容易膨胀得非常大。

方差膨胀对 Softmax 的危害

为什么内积结果方差太大，会导致注意力机制崩塌？

我们知道，注意力机制最终是通过 softmax\text{softmax}softmax 激活函数将内积转化为概率分布的。对于一个 KKK 维的输入向量 zzz，softmax\text{softmax}softmax 的输出为： si=softmax(z)i=ezi∑j=1Kezjs_i = \text{softmax}(z)_i = \frac{e^{z_i}}{\sum_{j=1}^K e^{z_j}}si​=softmax(z)i​=∑j=1K​ezj​ezi​​

当输入 zzz 的各元素之间差异非常大时（即方差极大），假设其中某一项 zmz_mzm​ 明显大于其他项，那么经过指数放大后，ezme^{z_m}ezm​ 会远远主导分母，导致： sm≈1,sj≈0(∀j≠m)s_m \approx 1, \quad s_j \approx 0 \quad (\forall j \neq m)sm​≈1,sj​≈0(∀j=m)

此时，softmax\text{softmax}softmax 将退化为一个独热编码 (One-hot Encoding) 的硬性最大值选择器。这会导致两个极其严重的灾难：

  1. 梯度消失 (Vanishing Gradient)：由于输出接近 0 或 1，softmax\text{softmax}softmax 函数在此处的导数接近于 0，反向传播时的梯度几乎无法向上传递，导致网络无法收敛。
  2. 多模态丧失：模型被迫只能关注单一的一个 Token，无法将注意力平摊在多个相互关联的词汇上。

通过除以 dk\sqrt{d_k}dk​​ 进行缩放 (Scaling) 以后，我们成功将内积的方差拉回到了稳定的 111： Var(q⋅kdk)=1dkVar(q⋅k)=dkdk=1\text{Var}\left( \frac{q \cdot k}{\sqrt{d_k}} \right) = \frac{1}{d_k} \text{Var}(q \cdot k) = \frac{d_k}{d_k} = 1Var(dk​​q⋅k​)=dk​1​Var(q⋅k)=dk​dk​​=1

这就保证了无论模型维度 dkd_kdk​ 膨胀到多大，点积的分布依然稳定，Softmax 的输出梯度饱满，模型得以稳定训练。

极简代码验证

我们可以通过短短几行 Python (PyTorch) 代码，在计算机上完美重现这一数学结论：

import torch
import torch.nn.functional as F

# 设置大维度
dk = 1024
batch_size = 10000

# 随机生成两个独立同分布的标准正态分布向量
q = torch.randn(batch_size, dk) # 期望 0, 方差 1
k = torch.randn(batch_size, dk) # 期望 0, 方差 1

# 1. 计算未缩放的点积
dot_product = (q * k).sum(dim=-1)
print(f"【未缩放】均值: {dot_product.mean().item():.4f}, 方差 (理论应为 {dk}): {dot_product.var().item():.4f}")

# 2. 计算缩放后的点积
scaled_dot_product = dot_product / (dk ** 0.5)
print(f"【 缩放 】均值: {scaled_dot_product.mean().item():.4f}, 方差 (理论应为 1.0): {scaled_dot_product.var().item():.4f}")
